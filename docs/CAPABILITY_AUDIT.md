## Release rule

No roadmap-complete release or website claim may be published while any required-completion cell above lacks executable evidence. Local development commits may advance the ledger, but GitHub publication is held until the complete compiler, runtime, official packages, documentation, editor tooling, reference applications, installers, and site pass the final validation matrix together.
